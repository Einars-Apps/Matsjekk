Hva denne siden forklarer

Denne siden beskriver hvordan Mat Sjekk velger ut og presenterer nyheter om Bovaer, insektsmel og GMO i fiskefor. Målet er å gi brukere mest mulig presis og etterprøvbar informasjon, med lenker til originalkilder.

Redaksjonelt fokus

Tema 1: Bovaer
Artikler om bruk, regulering, dyrehelse, forbrukerreaksjoner og markedskonsekvenser.
Tema 2: Insektsmel
Artikler om bruk i fôr- og matkjeder, næringsfaglig diskusjon og regelverk.
Tema 3: GMO i fiskefôr
Artikler om råvarer i oppdrettsfôr, sporbarhet, import og regulatoriske endringer.

Hvordan artikler vurderes

  1. Kildekontroll: Vi prioriterer aviser og nettaviser med tydelig avsender, redaksjonell struktur og sporbar publisering.
  2. Temarelevans: Artikler må ha konkret relevans til Bovaer, insektsmel eller GMO-fiskefôr.
  3. Språk og region: Feeden er regiontilpasset, men kilder fra flere europeiske land kan vises når de er relevante.
  4. Moderering: Innsendte lenker publiseres ikke direkte; de går til moderering først.
  5. Rydding: Artikler med tydelig feil, spam eller uten tematisk relevans kan fjernes.

Hva vi ikke gjør

Mat Sjekk er ikke en medisinsk eller juridisk rådgivningstjeneste. Vi fastslår ikke hva brukere skal mene eller kjøpe. Vi presenterer kilder, kontekst og sammenlignbar informasjon slik at brukeren kan ta egne valg.

Vi bruker ikke feeden til å promotere sosiale medier som primærkilder. Nyhetsutvalget er begrenset til relevante avis- og nettaviskilder.

Åpenhet og forbedringer

Har du forslag til forbedringer av metode eller kildevalg, kan du sende inn via kontaktsiden eller nyhetsinnsending. Vi oppdaterer metodegrunnlaget fortløpende når nye kilder, regler eller faglige vurderinger krever det.

Se også kildekriterier for konkrete krav til kildene som slipper inn i nyhetsfeeden.
