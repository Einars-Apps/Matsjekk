Formål

Denne siden forklarer hvilke kilder som kan vises i Mat Sjekk sin nyhetsfeed, og hvilke krav som må oppfylles. Kriteriene brukes for å redusere støy, øke relevans og forbedre kvalitet for brukeren.

Minstekrav for kilder

  1. Tydelig avsender: Kilden må ha identifiserbar nettavis/avisprofil.
  2. Publiseringsspor: Artikler skal ha fungerende URL og lesbar publiseringskontekst.
  3. Tematisk relevans: Innholdet må handle om Bovaer, insektsmel eller GMO i fiskefôr.
  4. Geografisk relevans: Europeiske kilder prioriteres, men internasjonale kilder kan inkluderes når de er faglig relevante.

Kilder som normalt ikke tas inn

  • Rene sosiale medieposter uten redaksjonell publisering.
  • Spam, aggregater uten tydelig opprinnelig kilde, eller dublikatlenker.
  • Artikler uten tydelig kobling til de tre hovedtemaene.

Moderering og korrigering

Alle innsendte artikler behandles i modereringsflyt. Dersom en artikkel senere vurderes som feil, utdatert eller irrelevant, kan den fjernes eller korrigeres.
