# Food Check CN

## Overview
Food Check CN is a Flutter application designed to help users manage their shopping lists, scan barcodes, and find nearby stores. The app supports multiple languages, including Chinese and English, to cater to a diverse user base.

## Features
- **Multi-language Support**: The app automatically adjusts to the device's language settings, currently supporting Chinese and English.
- **Shopping List Management**: Users can create and manage their shopping lists efficiently.
- **Barcode Scanning**: Integrated barcode scanning functionality for quick product lookup.
- **Store Finder**: Helps users locate nearby stores based on their current location.
- **User-friendly Interface**: Intuitive design with easy navigation and accessibility.

## Project Structure
The project is organized into several directories, each serving a specific purpose:
- **lib/**: Contains the main application code, including models, providers, screens, and widgets.
- **test/**: Includes widget tests and localization tests to ensure code quality and functionality.
- **android/** and **ios/**: Platform-specific configurations for Android and iOS applications.
- **l10n/**: Localization files for supporting multiple languages.

## Getting Started
To run the application, follow these steps:
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd food_check_cn
   ```
3. Install the dependencies:
   ```
   flutter pub get
   ```
4. Run the application:
   ```
   flutter run
   ```
